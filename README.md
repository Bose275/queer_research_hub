# Queerposium Website

A static, responsive landing page for Queerposium / Queer Research Hub.

## Files

- `index.html` — page content
- `styles.css` — styling and responsive layout
- `script.js` — mobile navigation
- `README.md` — this guide

## What to edit first

In `index.html`, replace:

- `May 2027 · TBA`
- `University of Calgary`
- `https://example.com`
- `queerresearchhub@example.com`
- placeholder speaker names
- draft program details

## How to preview locally

Open `index.html` in your browser.

## How to host

Easy options:

1. Upload the folder to GitHub Pages.
2. Drag the folder into Netlify.
3. Upload the files to any standard web host.

## Notes

The site is intentionally static, accessible, and easy to revise without a build system.
